# Wuzi Codes

A personal blog and project archive. Original templates and CSS, Markdown content, static HTML generated by Hugo. Canonical address: https://wuzi.dev.

## Build and preview

Requirements: Node.js 22+, Python 3 (checks/preview), and `tar` on Linux. No npm dependencies or Go installation are required.

```sh
npm run check
npm run preview
```

Open http://127.0.0.1:4173. The build script downloads Hugo **0.169.0** on Linux x64 and verifies its pinned SHA-256 before extracting it. On other platforms, install that exact Hugo version and set `HUGO_BIN` to the executable path. Generated files live in `dist/`; downloaded tooling lives in ignored `.tools/`.

`npm run build` always makes a clean production build, excluding drafts and future-dated content. The output is ordinary static HTML, CSS, JavaScript, XML and images and can be served by other static hosts.

## Verification

`npm test` checks the generated site against the migration manifest: original source/media hashes, complete article text, image order, project links, feed identities/dates, aliases, retired URLs, internal links, sitemap and robots. Browser behavior tests exercise theme persistence/failure and the analytics hostname boundary. Visual changes require desktop/mobile browser checks in both themes.

The analytics script loads the existing GA4 integration only on HTTPS `wuzi.dev` or `www.wuzi.dev`. It remains inactive on local servers and Sites preview/publication hostnames. The theme and copy controls progressively enhance HTML; navigation and articles work without JavaScript.

## Hosting

`.openai/hosting.json` identifies the existing Site and its static `dist/` directory. Use the Sites plugin to save and deploy verified source versions. GitHub is the maintained source repository; Sites has its own deployment source remote. Push the same tested commit to both. A GitHub push alone does not publish the Site.

Never store credentials in files or Git. Pass temporary Sites credentials through the supported helper's hidden stdin interface. Commit source changes with a lowercase subject before invoking that helper. Keep archives outside the checkout. Domain DNS is managed separately by Wuzi; do not repoint it until anonymous access, routes, HTTPS, RSS and indexing checks pass.
